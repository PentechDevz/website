Every project starts with a real problem. Here's how we worked through four of them.

01Health & fitness2025

Sports Performance App

An app that helps athletes and coaches track training and see progress across a season.

The problem
Coaches tracked sessions in notebooks and group chats, so progress was hard to see and easy to lose.
What we built
A web app where athletes log sessions and coaches see each player's load, trends and goals on one dashboard.
The outcome
Coaches plan the week from real data, and athletes see their own progress at a glance.

Built with

  • React
  • Node.js
  • PostgreSQL
  • Figma

02Gamified experience2025

Digifikile

A gamified experience that turns building digital skills into a series of short challenges.

The problem
Learners were dropping out of long, text-heavy courses before they finished them.
What we built
Bite-sized challenges with points, levels and streaks, designed to run smoothly on low-cost phones.
The outcome
Learners come back to finish the next level, not just the next lesson.

Built with

  • Vue.js
  • TypeScript
  • Django
  • MongoDB

03Campus guide2025

TUT Guide

A campus guide that helps new students find buildings, services and their way around.

The problem
New students struggled to find lecture venues and student services across a large campus.
What we built
A searchable map and directory of buildings, offices and services, with step-by-step directions.
The outcome
First-years spend less time lost and more time where they need to be.

Built with

  • Next.js
  • TypeScript
  • Spring Boot
  • MySQL

04Certification platform2025

DocSecure

A platform for issuing and verifying certificates, so anyone can check a document is genuine.

The problem
Paper certificates were easy to forge and slow to verify, often taking calls and emails back and forth.
What we built
Digital certificates with a unique code, plus a public page where anyone can verify one instantly.
The outcome
Employers can check a certificate in seconds instead of days.

Built with

  • C#
  • ASP.NET
  • SQL Server
  • React
